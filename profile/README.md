# Stratus

Self-hosted personal cloud: photo backup, calendar, contacts, music and video.
Same goals as Nextcloud, radically fewer moving parts -- one Go binary, one
container, and standard protocols every existing client already speaks.

| repo | what it is |
|---|---|
| [stratus-backend](https://github.com/stratus-private-cloud/stratus-backend) | the server: WebDAV, tus, CalDAV, CardDAV, OpenSubsonic and a web UI |
| [stratus-app](https://github.com/stratus-private-cloud/stratus-app) | the iOS and Android client: camera-roll backup over plain WebDAV |
| [.github](https://github.com/stratus-private-cloud/.github) | the workspace: the principles every repo is held to, and the brand |

- Demo: https://stratus-demo.dropdatabase.es -- the last green `main`, emptied
  every hour. The password is the version string in its own page footer.
- Board: https://github.com/orgs/stratus-private-cloud/projects/1
